# How you provide feedback to the team members (especially the negative/constructive one) without hurting anyone? 
# If they are not performing properly, please give feedback EARLY ON. In the end, when/if they get a bad peer evaluation, I don't want them to be surprised.

## Michael Levin
Constructive feedback will be provided as early as possible on the team forum. This
may be done by providing comments on uploaded documents, team discussions, etc.

## Dilixiati Alifu
Feedback should always be specific, respectful, and timely, focused strictly on the work, not the person. If a member is underperforming, the team will address it early and privately first so they have a chance to improve. This ensures no one is surprised or blindsided by a poor peer evaluation at the end of the project.

## Tabor Elder
After the Completion of the assignment, and the next Facilitator is decided, the oncoming Facilitator will host a Critique Period where we can reflect on our performance, and prepare for better performance on the next assignment

## Jake Joiner
1. Giving constructive but not cowardly feedback is important, but it doesn't need to be done with a bludgeon. 
2. Reviewers should generally be polite but honest about observed issues. If a word is misspelled, point it out. If something could be done in a better way, suggest it. 
3. Using non-aggressive language is ideal. "It may be better to consider using a for loop here instead." 
4. Have pretty thick skin about review feedback received. It's not personal. 
5.  If there's some sort of personality problem/disagreement, the following is probably a good procedure: 
    1. If something is minor, overlook it. 
    2. If you feel strongly enough about a problem to address it, do so privately first if at all possible. Privately in the sense of one on one, with no other members present. 
    3. If a resolution cannot be gained privately, bring another member and go again privately.
    4. If a resolution still cannot be gained privately, bring it before everyone.
    5. Lastly, give no credit if we must, or go to an outside authority such as the teacher.
